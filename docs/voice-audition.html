一个必须说的风险

迷糊版的官方定义是“十六七岁少女”。如果夜谈的角色涉及恋爱、亲密或性暗示内容，不要用迷糊版做主线，观感和合规都不合适。它可以做非恋爱向的“学妹 / 小助手 / 拟人宠物”。偶像版是年轻成年女性，没有这个问题。

一句话判断

成年、温柔、恋人感：用偶像版，这 7 只里它最合适。憨憨少女、学妹、小助手：用迷糊版，记忆点更强。两个都要：偶像版做主线，迷糊版做妹妹或配角，声音有区分度。

想让它说夜谈的台词，只差一步

不需要 AstrBot，也不需要动 QQ。夜谈是 iOS App，直接调 BreezeBlue 的 HTTP 接口就行。

  1. 登录 breezeblue.ai，在开发者页创建一个 API Key。免费档每天可领 400 credits，够生成几十句测试。
  2. 把 Key 写进本机文件 ~/.breeze_key（只写一行），不要发在聊天里。我写好的脚本会从文件读，不回显。
  3. 我用夜谈的 6 句台词各生成一遍：撒娇、困倦、吃醋、安慰、笑骂、被测句。你听完再决定接不接。
  4. 决定接，就在 App 里加一个 BreezeVoiceClient，只给指定角色用；通话仍走本地引擎，语音条走云端。
为什么只用这一小步

样音是官方预置文稿，只能判断“音色底色”。真正决定适配的是它念夜谈台词时的表现，尤其是困倦、口是心非、带笑的骂这三句。这 6 句生成成本约 26 credits，不到一分钱一条。
