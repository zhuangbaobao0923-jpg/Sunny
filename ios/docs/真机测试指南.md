# 「夜谈」真机测试指南（本地免费语音版）

> 当前架构：**App 请求只发往你 Mac 上的本地 TTS 服务，代码里不存在任何云端/百炼路径，不会产生任何调用费用。**

## 一、语音链路总览

```
iPhone（夜谈 App）
   │  http（局域网）
   ▼
Mac 上的本地 TTS 服务（127.0.0.1 / 192.168.x.x : 9880）
   │  edge-tts 免费合成（微软晓晓/云希/云健/晓伊，无 Key、无配额）
   ▼
mp3 → App 播放（同一句话有缓存，不重复合成）
```

- 服务未启动时，App 自动回退 iPhone 系统离线语音，**不会哑掉**。
- 角色音质 → 音色映射：清冷少年=云希 Yunxi / 沉金男声=云健 Yunjian / 灵动机音=晓晓 Xiaoxiao / 软糯少女=晓伊 Xiaoyi。

## 二、每次测试前（Mac 侧）

**1. 启动本地语音服务**（终端执行）：

```bash
bash /Users/zhuangyiqing/Documents/newproject/ios/tools/start-tts.sh
```

看到以下输出即成功：

```
[bonjour] 已注册 _edgetts._tcp（192.168.169.2:9880），iPhone 打开 App 即自动发现
[local-tts] edge-tts 服务已启动（免费、无 Key、无云端请求）
```

记住输出里的 **真机 App 地址**（当前 Mac 的局域网 IP 是 `192.168.169.2`）。

**2. 验证服务活着**（可选）：浏览器打开 `http://127.0.0.1:9880/health`，应显示 `{"status":"ok",...}`。

⚠️ 首次启动 macOS 防火墙可能弹「是否允许 python3 接受传入连接」→ 点**允许**。

## 三、把 App 装到真机

方式 A（推荐）：数据线连接 iPhone → 解锁保持亮屏 → Xcode 打开 `ios/AICompanion.xcodeproj` → 顶部选中你的 iPhone → **⌘R**。

方式 B（命令行）：解锁手机后执行：

```bash
bash /Users/zhuangyiqing/Documents/newproject/ios/run-device.sh
```

- 构建已验证可通过（BUILD SUCCEEDED）。
- 免费开发者证书签名的 App **7 天后过期**，过期后重新 ⌘R 或重跑脚本即可。

## 四、真机上的 App 内设置（只需一次）

1. 打开「夜谈」→ 我的 → 设置 → **语音引擎（本地免费）**
2. 首次会弹「本地网络」权限 → 点**允许**（用于自动发现 Mac）
3. 等状态变绿 **「服务已连接」**（Bonjour 自动发现，无需手输 IP）
4. 若一直显示未连接 → 手动把「服务地址」改成 `http://192.168.169.2:9880`（以 start-tts.sh 输出的为准）
5. 点四个音色右侧 ▶ 试听确认出声
6. 回聊天页点气泡上的播放键 → 角色用微软神经音色说话

## 五、常见问题

| 现象 | 原因与解决 |
|---|---|
| 设置页一直「服务未启动」 | ① 服务没启动 → 回到第二步；② 防火墙拦了 → 系统设置→网络→防火墙放行 python3；③ 手机和 Mac 不在同一 Wi-Fi |
| 自动发现失败 | 本地网络权限被拒：设置 → 隐私与安全性 → 本地网络 → 打开「夜谈」；或直接手输 IP |
| 昨天能用今天不行 | Mac 的局域网 IP 变了（DHCP）。看 start-tts.sh 启动输出的新 IP，在 App 设置页更新（或重装后重走自动发现） |
| 声音是机器味的系统音 | 说明走了回退，本地服务没连上 → 按上面排查 |
| App 打不开提示不受信任 | 设置 → 通用 → VPN与设备管理 → 信任开发者证书 |
| Mac 合成慢（首次 2~5 秒） | edge-tts 首次请求微软服务器取流；同一句话有缓存，第二次秒出 |
